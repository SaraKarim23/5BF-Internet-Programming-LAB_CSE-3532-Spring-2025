# 📱 Social Media Platform

A modern, responsive social media web application built using **React**, **Appwrite**, **Tailwind CSS**, and **ShadCN UI**. This project was developed as part of the *Tools and Technologies for Internet Programming* course.

## 👨‍💻 Team Members

- **Name:** Kamrun Nahar Kumkum  
- **ID:** C233420

## 🚀 Features

- 🔐 User Authentication (Sign up, Login, Logout)
- 📝 Create, Read, Update, Delete (CRUD) posts
- 📸 Image upload and preview with Appwrite storage
- 🧑‍💼 User profile management
- 📱 Fully responsive layout
- ⚡ State management and data fetching with React Query (TanStack Query)

## 🛠️ Tech Stack

| Area       | Tools & Libraries                          |
|------------|---------------------------------------------|
| Frontend   | React, Tailwind CSS, ShadCN UI              |
| Backend    | Appwrite (Auth, Database, Storage)          |
| State/Data | TanStack Query (React Query)                |
| Dev Tools  | Vite, Git, GitHub                           |

## 📂 Project Structure

```bash
📁 src
````

## 🧪 Getting Started

### 1. Clone the repo

```bash
git clone https://github.com/KaMRuNs/Social_Media_Platform.git
cd Social_Media_Platform
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure Appwrite

* Create a project in [Appwrite](https://appwrite.io/).
* Set up:

  * Database
  * Authentication
  * Storage bucket
* Replace the required environment values in `.env` file (see `.env.example` if available).

### 4. Start the development server

```bash
npm run dev
```
