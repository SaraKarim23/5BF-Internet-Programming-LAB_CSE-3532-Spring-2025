## 📌 About This Project

**Event Management System** is a web-based application designed to make event planning and management easier, faster, and more professional. It offers different categories such as **social**, **corporate**, **educational**, **political**, and **sports** events. Users can create events, handle bookings, and manage participant data all in one place.

## 🛠️ Tech Stack


### 🎯 **Frontend**

* 🧩 **HTML5** – Structure of web pages
* 🎨 **CSS3** – Styling with custom designs and animations
* ⚡ **JavaScript (Vanilla)** – Interactive client-side logic
* ✨ **AOS.js** – Scroll animations for smoother UI
* 📱 **Responsive Design** – Optimized for mobile & desktop views


### 🧠 **Backend**

* 🛠 **PHP** – Handles server-side logic and data processing
* 🔐 **User Auth System** – Signup/login, session handling
* 🔄 **AJAX (optional)** – For dynamic content loading without refresh


### 🗃️ **Database**

* 🐬 **MySQL** – Stores event data, users, bookings, categories
* ⚙️ **phpMyAdmin** – GUI for managing database easily
* 🖥️ **XAMPP** – Local server environment (Apache + MySQL + PHP)

### 🤖 **Smart Features**

* 📩 **PHPMailer** – Send email confirmations after booking
* 📆 **Dynamic Calendar (JS)** – Display upcoming events by date
* ⏳ **Countdown Timer** – For upcoming events
* 🧠 **Event Suggestion Logic (Basic)** – Recommend popular events
  

### 📌 **Deployment** 

* 🖥️ **Local Testing** – XAMPP server for development
* ☁️ **000WebHost / InfinityFree** – Free hosting for PHP projects
* 🌐 **GitHub Pages (Frontend Only)** – Host HTML/CSS/JS UI
* 📦 **cPanel Hosting (Full Stack)** – For real-world deployment
